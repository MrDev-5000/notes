# Solving Quadratics
 A quadratic equation can be written in the form $ax^2 + bx + c$
## Using factorize

### Quadratic formula
$$x = \frac{{-b \pm \sqrt{b^2 - 4ac}}}{2a}$$


### Completing the square
- $x^2 + bx = \left( x + \frac{b}{2} \right)^2 - (\frac{b}{2})^2$
- $ax^2 + bx + c = a\left( x + \frac{b}{2a} \right)^2 + (c - \frac{b^2}{4a})$

### Quadratic Graphs
when $f(x) = ax^2 bx + c$, the graph of $y = f(x)$ has a parabola shape
- when $a$ is positive the parabola has this shape: $\smallsmile$
- when a is negative the parabola has this shape: $\smallfrown$
- the coordinates of the turning point of a quadratic graph by completing the square. 
     - if $f(x) = a(x + p)^2 + q$, the graph of $y = f(x)$ has a turning point at $(-q, p)$

### Discriminant
- if $b^2 - 4ac > 0$ then $f(x)$ has two distinct real roots

- if $b^2 - 4ac = 0$ then $f(x)$ has one repeated root
-  if $b^2 - 4ac < 0$ then $f(x)$ has no real roots
