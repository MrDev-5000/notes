
# Index Laws & Surds

-  $a^m \times a^n = a^{m+n}$
- $a^m \div a^n = a^{m-n}$ 
- $(a^m)^n = a^{mn}$
- $(ab)^n = a^nb^n$
- $\left( \frac{a}{b} \right)^n = \frac{a^n}{b^n}$
- $\left( \frac{a}{b} \right)^{-n} = \frac{b^n}{a^n}$
- $a^{-n} = \frac{1}{a^n}$
- $a^\frac{n}{m} = \sqrt[\leftroot{1} \uproot{4} m] {a^n} = (\sqrt[\leftroot{1} \uproot{4} m]{a})^n$ 
- $a^\frac{1}{m} = \sqrt[\leftroot{1} \uproot{4} m] {a}$
- $a^0 = 1$
- $(\sqrt{a})^2 = a$
- $\sqrt{\frac{a}{n}} = \frac{\sqrt{a}}{\sqrt{b}}$
- $\sqrt{ab} = \sqrt{a} + \sqrt{b}$
- $\sqrt{a} \times \sqrt{a} = a$
- $n\sqrt{a} \times m\sqrt{a} = amn$
- $n\sqrt{a} - m\sqrt{a} = (n-m)\sqrt{a}$
- $n\sqrt{a} + m\sqrt{a} = (n+m)\sqrt{a}$


>[!Warning]
> the rules for surds do not appliy to $-Ve$ numbers 
# Algebraic Expressions
- $a(b + c) = ab + ac$
- $(a + b)^2 = a^2 + 2ab + b^2$
- $(a - b)^2 = a^2 - 2ab + b^2$
- $a^2 + b^2 = (a + b)^2 - 2ab$
- $a^2 - b^2 = (a + b)(a - b)$

# Rationalizing denominator
if a fraction has a surd in the **denominator**, it is sometimes useful to rearrange it so that the denominator is a rational number

- Fractions in the form $\frac{1}{\sqrt{a}}$, multiply the numerator and denominator by $\sqrt{a}$
$$\frac{1}{\sqrt{a}} \times \frac{\sqrt{a}}{\sqrt{a}} = \frac{\sqrt{a}}{a}$$

- Fractions in the form $\frac{1}{a + \sqrt{b}}$, multiply the numerator and denominator by $(a-\sqrt{b})$ 
$$\frac{1}{a+\sqrt{b}} \times \frac{a-\sqrt b}{a-\sqrt{b}} = \frac{1(a-\sqrt{b})}{(a+\sqrt{b})(a-\sqrt{b})} = \frac{a-\sqrt{b}}{a^2 - b^2}$$

- Fractions in the form $\frac{1}{a - \sqrt{b}}$, multiply the numerator and denominator by $(a+\sqrt{b})$
$$\frac{1}{a - \sqrt{b}} = \frac{a + \sqrt{b}}{a + \sqrt{b}} = \frac{1(a+\sqrt{b})}{(a-\sqrt{b})(a+\sqrt{b})} = \frac{a + \sqrt{b}}{a^2 - b^2}$$
