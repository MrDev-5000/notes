## Stationary points
A **stationary point** on a curve is any point where the curve has **gradient zero**.

| Type of stationary point | $f'(x-h)$ | $f'(x)$ | $f'(x+h)$ |
| ------------------------ | :-------: | :-----: | :-------: |
| Local maximum            | Positive  |    0    | Negetive  |
| Local minimum            | Negetive  |    0    | Positive  |
| Point of inflection      | Negetive  |    0    | Negetive  |
| Point of inflection      | Positive  |    0    | Positive  |


## Sketching gradient functions
|       $y=f(x)$       |            $y = f'(x)$             |
| :------------------: | :--------------------------------: |
|  Maximum or minimum  |          Cuts the x-axis           |
| Point of inflection  |         Touches the x-axis         |
|  Positive gradient   |          Above the x-axis          |
|  Negative gradient   |          Below the x-axis          |
|  Vertical asymptote  |         Vertical asymptote         |
| Horizontal asymptote | Horizontal asymptote at the x-axis |
