## Stationary points
A **stationary point** on a curve is any point where the curve has **gradient zero**.
- the function $f(x)$ is increasing on the interval $[a, b]$ if $f'(x) \geq 0$ for all values of x such that $a < x < b$
- the function $f(x)$ is decreasing on the interval $[a, b]$ if $f'(x) \leq 0$ for all values of x such that $a < x < b$
- differentiating y = f(x)
