### Constants
**Electron charge:** $e = -1.60\times 10^{-19}C$
**Electron mass:** = $m_{e}9.11\times 10^{-31}kg$
**Electron volt:** $1eV = 1.60\times 10^{-19}J$
**Gravitational field strength:** $g = 9.81N kg^{-1}$
**Planck constant:** $h = 6.63\times 10^{-34}Js$
**speed of light in vacuum:** $c = 3.00\times 10^8ms^{-1}$

## motion
- $v = \frac{s}{t}$
- $a = \frac{\Delta v}{t}$
- $s = ut + \frac{1}{2} at^2$
- $v = u + at$
- $s = \frac{(u + v)t}{2}$
- $v^2 = u^2 + 2as$
- $s = vt - \frac{1}{2}at^2$

>[!INFO] Where
>$s = \text{displacement}$
>$u = \text{inital velocity}$
>$v = \text{final velocity}$
>$a = \text{acceleration}$
>$t = \text{time}$


#### Forces
- $\sum F = ma$
- $W = mg$

>[!Info] Where
>- $F(W) = force$
>- $m = \text{mass}$
>- $g = \text{gravitational field strength}$

#### Momentum
- $\rho  = mv$

> [!Info] Where
>- $\rho = \text{momentum}$
>- $m = \text{mass}$
>- $v = \text{velocity}$

#### Moment
- $moment = Fx$
- $\text{moment} = f_{2}\sin \theta \times d$
- $\text{moment} = f_{2} \times x_{2}$

#### Energy
- Weight: $W = Fd$
- Potential Energy: $PE = mgh$
- **Elastic Energy** $\to$ $E_{e} = \frac{1}{2}ke^2$
- **Kinetic Energy:** $\text{KE} = \frac{1}{2}mv^2$
- **Power:** $P = \frac{W}{t} = \frac{Fs}{t} = Fv$
- **Efficiency:** $\varepsilon =\frac{\text{useful output}}{\text{total input}}\times 100 \%$

>[!Info] Where
>- $W = \text{work done (J)}$
>- $PE =\text{potential energy}$
>- $E_{e} = \text{elastic energy}$
>- $KE = \text{kinetic energy}$
>- $\varepsilon = \text{efficiency}$
>- $k = \text{spring constant}$
>- $e = \text{extension}$
>- $h = height$
>- $g = gravity$
>- $m = mass$
>- $t = time$
>- $F = force$
>- $s = second$
>- $v = velocity$
>- $P = power$

## Fluids
- **density:** $\rho = \frac{m}{V}$
- **upthrust:** $F = \rho Vg$
- **terminal velocity:** $v_{term} = \frac{2r^2g(\rho_{s} - \rho_{f})}{9\eta}$
- **stokes law:** $F = 6\pi \eta rv$

> [!Info] Where
> - $\rho = \text{density}$ 
> - $m = \text{mass}$ 
> - $V = \text{volume}$ 
> - $F = \text{force}$ 
> - $g = \text{gravitational field strength}$ 
> - $v_{\mathrm{term}} = \text{terminal velocity}$ 
> - $r = \text{radius of the sphere}$ 
> - $\rho_s = \text{density of the sphere}$ 
> - $\rho_f = \text{density of the fluid}$ 
> - $\eta = \text{dynamic viscosity}$ 
> - $v = \text{velocity}$

## Solids
- Hooke's Law: $F = hx$
- Elastic Energy: $E = \frac{1}{2}F \Delta x$
- Elastic Energy: $E = \frac{1}{2}k\Delta x^2$
- Stress: $\sigma = \frac{F}{A}$
- Strain: $\varepsilon = \frac{\Delta x}{x}$
- Young Modulus: $E = \frac{\sigma}{\varepsilon}$
- Young Modulus: $E = \frac{Fl}{Ax}$

###### Stress-Strain Graph 
- Area under the graph = energy density 
- Gradient in the linear region = Young modulus

> [!Info] Where
> $F = \text{force}$ 
> $k = \text{spring constant}$
> $x = \text{extension}$ 
> $\Delta x = \text{change in length}$ 
> $E_e = \text{elastic potential energy}$ 
> $\sigma = \text{stress}$ 
> $\varepsilon = \text{strain}$ 
> $A = \text{cross-sectional area}$
> $E = \text{Young modulus}$ 
> $l = \text{original length}$

## waves
- Wave Equation: $v = f\lambda$
- Wave Speed: $v = \sqrt{ \frac{T}{\mu}}$
- Snell's Law: $n_{1}\sin \theta_{1}=n_{2}\sin \theta_{2}$
- Refractive Index: $n = \frac{c}{v}$
- Critical Angle: $\sin c = \frac{1}{n}$
- Diffraction Grating: $m\lambda = d \sin \theta$

### Quantum Physics
- Intensity: $I = \frac{P}{A}$
- $E = hf$
- $hf = \phi +\frac{1}{2}mv^2$
- $\lambda = \frac{h}{p}$

> [!INFO] where 
> - $v = \text{wave speed}$
> - $f = \text{frequency}$ 
> - $\lambda = \text{wavelength}$ 
> - $T = \text{tension}$

> - $n = \text{refractive index}$
> - $n_1 = \text{refractive index of medium 1}$
> - $n_2 = \text{refractive index of medium 2}$
> - $c = \text{speed of light in vacuum}$
> - $\theta_1 = \text{angle of incidence}$
> - $\theta_2 = \text{angle of refraction}$
> - $c = \text{critical angle}$
> - $m = \text{diffraction order}$
> - $d = \text{grating spacing}$
> - $\theta = \text{diffraction angle}$
> - $I = \text{intensity}$
> - $P = \text{power}$
> - $A = \text{area}$

## Electricity
- $Q = ne$
- $I = \frac{\Delta Q}{\Delta t}$
- $I = nAvq$
- $V = \frac{W}{Q} = \frac{E}{Q}$
- $n = \frac{N}{V}$
- $V = IR$
- $R = \rho \frac{l}{A}$
- $P = IV$
- $P = I^2R$
- $P = \frac{V^2}{R}$
- $W= VIt$

|             | series                            | parallel                                                                    |
| ----------- | --------------------------------- | --------------------------------------------------------------------------- |
| **voltage** | $\varepsilon = V_{1}+V_{2}+V_{3}$ | $\varepsilon = V_{1} = V_{2} = V_{3}$                                       |
| Current     | $I = I_{1} = I_{2} = I_{3}$       | $I_{total}= I_{1}+I_{2}+I_{3}$                                              |
| resistance  | $R_{total} = R_{1}+R_{2}+R_{3}$   | $\frac{1}{R_{total}} = \frac{1}{R_{1}} + \frac{1}{R_{2}} + \frac{1}{R_{3}}$ |
> [!INFO] where 
> - $\varepsilon = \text{electromotive force}$ 
> - $\rho = \text{resistivity}$
> - $l = \text{lenght}$
> - $A = \text{cross section area}$
> - $N = \text{No of electrons}$
> - $V = \text{Volume}$
> - $n = \text{charge carrier density}$
> - $e = \text{}$
> - $t = \text{time}$
> - $v = \text{drift velocity}$
> - $q = \text{charge of 1 electron}$
> - $Q = \text{charge}$
> - $V = \text{potential difference}$ 
> - $I = \text{current}$
> - $I_{\mathrm{total}} = \text{total current}$
> - $R = \text{resistance}$ 
> - $R_{\mathrm{total}} = \text{total resistance}$ 
> - $V_1,V_2,V_3 = \text{potential difference across each component}$ 
> - $I_1,I_2,I_3 = \text{current through each component}$ 
> - $R_1,R_2,R_3 = \text{resistance of each component}$
