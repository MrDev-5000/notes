# <u>Method</u> - 1
# Object falling through a trap door 
## Materials Required
- Ball Bearing
- Digital Timer
- Electromagnet
- Trap-Door Switch
- Meter Rule

|     |
| :-: |

## Procedure
- Drop the object from rest and record the time $t$ taken
- Repeat the measurement for twice more and take mean value
- Measure and record the height $h$ fallen by the object
- Vary the height and find the corresponding time

# <u>Method</u> - 2
# Object falling through a light gate
## Materials Required
- Light Gate (Sensor)
- Data Logger (Digital Timer)
- Falling Object (dowel/weighted card)
- Meter Rule
- Vernier Caliper
- Tube, Stand

|     |
| :-: |

## Procedure
- Drop the object from rest and record the time taken $t$ for the dowel to pass through the light gate
- Repeat the measurement for twice more and work out the mean value
- Measure and record the height $h$ fallen by the object
- Vary the height and measure the corresponding time
- Velocity can be calculated $v = \frac{Length Of The Card}{Time}$
- $v^2 = u^2 + 2as$ where $u=0$, $a = g$ & $s = h$
- $v^2=2gh$ and comparison with $y=mx+c$
- plot a graph of $v^2$ against $h$ should be a straight line passing through the origin with gradient $2g$
- $g = \frac{gradient}{2}$
