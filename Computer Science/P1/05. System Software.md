
# Operating System
- it is a software that provides facilities for programs to be run which are beneficial to user
- it is also a interface between user & computer hardware
# Tasks carried out by the OS
## 1 - Memory Management
- Allocates memory to the processor
- Ensure fair usage of memory
- Organize memory by making use of virtual memory
- Keep processes separate 
- to release memory when a process stops

## 2 - Process Management
- Manages scheduling of processes 
- Allows multitasking
- handles priorities
- enables processes to share information
- prevents interface between the processes
- manages which resources the process requires

## 3 - Provision of user interface
- Allows the user to communicate with the hardware by making navigation around the system easier
- Provides facilities for user to input data
- Provides facilities to show output result to user
- E.g. CLI, GUI
#### Command Line Interface (CLI)
* User Types in instructions to open or launch a program
* User is in direct communication with the computer system
* Usually, several instructions are needed to be typed into open or launch a program
#### Graphical User Interface (GUI)
- User Interacts with the computer system by using icons
- User does not need to know where an application resides within computer
- User launches application using pointer

## 4 - Security Management Task
- sets up user account 
- Access rights
- Checks username and password
- Automatic backup
- System restores

## 5 - File Management
- Storage space divided into file allocation unit 
- Space allocated for particular files 
- Maintain directory structure
- Specifies logical method of file storage
- Provides file naming convention
- controls file access
- Specific tasks that can be performed on a file
- E.g. open, delete, copy

## 6 - Printer Mangement
- Installs printer driver
- Sends data to the printer
- Handles error messages
- sends commands to the printer

## 7 - Interrupt Handling
- Identifies priorities to the interrupt
- saves data on power outage
- Loads appropriate interrupt service routine
